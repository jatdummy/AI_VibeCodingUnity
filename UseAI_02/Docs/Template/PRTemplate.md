# PR Template

> Github에 등록할 PR의 양식.
>
> 사용자의 명시적인 명령 외에는 해당 양식을 기반으로 PR을 작성한다.
>
> 섹션별 작성 규칙은 `Docs/Documentation/GithubPRRule.md`를 따른다.

```markdown
# [말머리] [Title]

## 연결 Issue

- 

## 작업 내용

-
-
-

## 확인 사항

- [ ] Unity에서 실행 테스트해 보았다.
- [ ] 콘솔에 에러가 없다.
- [ ] 관계없는 파일이 같이 들어가지 않았다.
- [ ] 씬 파일이 들어갔다면 내가 그 씬의 소유자이다.
- [ ] 연결된 Issue의 완료조건(DoD)을 모두 충족했다.

## 화면

- 

## 참고사항

-

## 특이사항

-

```
