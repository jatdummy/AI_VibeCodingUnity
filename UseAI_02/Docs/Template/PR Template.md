# PR Templet

## Titel
- 대괄호 안에 말머리 기입 + 작업 내용 명사형으로 요약 , 말머리는 하단 내용을 참고한다.
  - [Feat] : 새로운 기능 추가
  - [Fix] : 버그 수정
  - [Docs] : 문서 파일 작성 및 수정
  - [Refactor] : 동작 변화 없는 구조 개선, 씬/프리팹 변경
  - [Asset] : 이미지, 사운드, 폰트 리소스 추가 및 교체
  - [Chore] : 설정, 패키지 등 잡일 + 공백정리, ProjectSettings 변경

## 작업 내용
- 해당 브랜치에서 작업한 내용을 상세히 기록한다_ 명사형기록을 권장

## 확인 사항
- [ ] Unity에서 실행 테스트해 보았다.
- [ ] 콘솔이 에러가 없다.
- [ ] 관계없는 파일이 같이 들어가지 않았다.
- [ ] 씬 파일이 들어갔다면 너가 그 씬의 소유자이다.

## 화면
- 필요시 참고용 이미지 화면을 첨부한다.

## 참고사항
- 변경되었거나, 해당 이슈 혹은 PR에서 중요한 파일의 경로

## 특이사항
- 전달사항 및 우려사항이 있다면 기입한다.
