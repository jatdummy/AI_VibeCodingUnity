# 02. AI 작업 지침

> AI(Claude 등)가 이 프로젝트에서 작업할 때 반드시 지켜야 할 규칙입니다.

## 1. 설명 방식
1. **모든 변경에는 이유를 설명한다.** "무엇을 바꿨는지"보다 "왜 이렇게 작성했는지(의도)"를 먼저 말한다.
2. **코드 위치를 정확히 알려준다.** 추가·수정할 코드는 어느 파일의, 어떤 기존 코드를 찾아서, 그 위/아래 중 어디에 넣는지 명시한다.
3. 새로운 Unity API나 C# 문법이 나오면 한두 줄로 개념을 덧붙인다.
4. 여러 방법이 가능하면 선택지와 장단점을 짧게 비교한 뒤 추천안을 제시한다.

## 2. 코드 수정 규칙
1. **내가 작성한 주석은 절대 수정·삭제하지 않는다.** 필요하면 그 옆에 새 주석을 추가만 한다.
2. 요청받은 범위만 수정한다. 관련 없는 리팩터링·이름 변경·포맷 변경은 먼저 제안하고 허락을 받는다.
3. 파일 전체를 다시 쓰기보다 **바뀐 부분만** 보여준다. (전체가 필요하면 내가 요청함)
4. 한 번에 하나의 기능 단위로 작업한다. 큰 기능은 단계로 나눠 진행한다.
5. 새 패키지·에셋·외부 라이브러리 도입은 반드시 먼저 물어본다.
6. `.unity`(씬), `.prefab`, `.meta` 파일은 직접 텍스트로 편집하지 않는다. 에디터에서 할 작업은 "에디터에서 이렇게 설정하세요"로 안내한다.
7. 확실하지 않은 Unity API는 추측하지 말고 불확실하다고 밝힌다.
8. 코드는 `03_code-convention.md`, 파일 위치는 `04_folder-structure.md` 규칙을 따른다.

## 3. 작업 마무리
- 작업이 끝나면 **커밋 메시지 초안**(`05_git-convention.md` 형식)을 함께 제안한다.
- `01_project-context.md`의 "현재 진행 상황"에 갱신할 내용이 있으면 알려준다.
